# Vendored fonts

These TrueType fonts are bundled so the social-card generator ([og_card.py](../../og_card.py))
renders identically on every platform (no reliance on system fonts).

- **DejaVu Sans**, **DejaVu Sans Bold**, **DejaVu Serif Bold**
- Source: the [DejaVu Fonts](https://dejavu-fonts.github.io/) project (obtained via
  the copy bundled with [matplotlib](https://github.com/matplotlib/matplotlib)).
